# SORAZ — Snack Outside The Script 🥢✨

> **Asian Pop-Culture Street Snacks & Ramune Crafted For India**

SORAZ brings the iconic treats from anime, K-dramas, C-dramas, and viral night-market reels directly to India. Crafted fresh with honest ingredients, bold flavor balance, and tuned for Indian palates.

---

## 🍱 Product Lineup

### 🇯🇵 Japan (Tokyo Konbini & Matsuri Classics)
- **Ramune**: Authentic Japanese marble-popper citrus soda
- **Taiyaki**: Crisp golden fish-shaped waffles with warm sweet fillings
- **Mitarashi Dango**: Chewy skewered rice dumplings glazed in sweet soy caramel

### 🇰🇷 Korea (Seoul Street Food & K-Drama Cravings)
- **Tteokbokki**: Spicy sweet glossy rice cakes
- **Korean Corn Dogs**: Ultra-crunchy, saucy cheese-pull sticks
- **Fruit Tanghulu**: Glass-crack candied fruit skewers

### 🇨🇳 China & 🇹🇭 Thailand (Night Market Legends)
- **Haw Flakes & Milk Candy**: Classic sweet-tart nostalgic pocket candies
- **Thai Seaweed Crisps**: Cult-favorite roasted seaweed sheets
- **Mango Sticky Rice & Thai Milk Tea**: Authentic coconut-sweet and spiced street drinks

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Routing**: [TanStack Router](https://tanstack.com/router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **State Management**: [TanStack Query](https://tanstack.com/query)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Backend & Waitlist**: Private Google Sheets Apps Script Web App API
- **Hosting**: [Vercel](https://vercel.com/)

---

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/Arjun006-coder/SORAZ.git
cd SORAZ

# Install dependencies
npm install  # or bun install

# Start development server
npm run dev

# Build for production
npm run build
```
